
# UserService 🧑‍💻

Welcome to the **UserService** repository! This project contains a microservice designed for managing user configurations. It allows users to perform key actions such as changing their password, updating their username, viewing the current time, and deleting their account. The service uses **SQL Server** to store user data and manage configurations securely.

## Description 🔐

UserService is a microservice that focuses on user management operations. This service is designed to be part of a larger system, allowing users to perform essential functions related to their account.

### Core Features ⚙️
- **Change Password:** Allows users to securely change their password.
- **Change Username:** Allows users to update their username.
- **View Current Time:** Provides users with the ability to check the current time.
- **Delete Account:** Allows users to permanently delete their account and all associated data.
- **SQL Server Database:** All user data and configurations are securely stored in an SQL Server database.

## Technologies Used 🛠️

- **SQL Server:** The database used for securely storing user data.
- **Microservices Architecture:** The system is designed as a microservice, allowing easy integration into a larger system and facilitating scalability and maintenance.
